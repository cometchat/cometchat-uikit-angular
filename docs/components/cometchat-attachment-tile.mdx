The `CometChatAttachmentTileComponent` (selector `cometchat-attachment-tile`) renders a single staged attachment in the message composer's attachment tray. It shows the file by type (an image/video square or a file/audio card), overlays the current upload status, and exposes cancel, remove, retry and open actions.

<Note>
  This is an **internal** component. It is not exported from `@cometchat/chat-uikit-angular` (it is absent from the components barrel used by `public-api.ts`), so you cannot import it into your own app. It is rendered by [`CometChatAttachmentTray`](/components/cometchat-attachment-tray), which is itself rendered by [`CometChatMessageComposer`](/components/cometchat-message-composer). This page documents its behaviour and styling hooks for theming and reference.
</Note>

## Overview

- **Rendering by type**: `image` and `video` render as a square thumbnail; `file` renders as a card with a coloured file-type icon, the file name and a meta line such as `PDF · 2.4 MB`; `audio` renders as a playable card
- **Video tiles**: Show a centred play affordance and an `mm:ss` duration badge once the duration is known
- **Audio tiles**: Play/pause button, seekable bar and `current/duration` time; playback is enabled only after the upload succeeds, and only one tray audio tile plays at a time
- **Upload status**: Progress ring while uploading, a retry badge when a retryable upload failed, and an error badge when the file was rejected
- **Top-right ✕ button**: Revealed on hover/focus; cancels the upload while in flight, otherwise removes the tile
- **Open preview**: Uploaded image and video tiles are clickable (and keyboard-activatable with Enter/Space) to open a fullscreen preview
- **Error tooltip**: A rejected tile shows its upload error in a tooltip on hover/focus, clamped inside the composer's width

## Usage in Context

The tile is not used directly. The tray renders one tile per staged attachment and maps each output to `MediaUploadTrayService`:

```html
<!-- cometchat-attachment-tray.component.html (internal) -->
@for (t of tray.tiles(); track t.fileId) {
  <div class="cometchat-attachment-tray__item" role="listitem">
    <cometchat-attachment-tile
      [tile]="t"
      (cancelClick)="tray.cancel($event)"
      (removeClick)="tray.remove($event)"
      (retryClick)="tray.retry($event)"
      (tileClick)="openViewer($event)"
    ></cometchat-attachment-tile>
  </div>
}
```

## Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `tile` | `AttachmentFile` | **required** | The staged attachment to render: its file, type (`'image' \| 'video' \| 'audio' \| 'file'`), name, size, upload status, progress and optional error message |

`AttachmentFile` is exported as a type from `@cometchat/chat-uikit-angular` (via the message composer). The fields the tile reads are `type`, `name`, `size`, `mimeType`, `file`, `thumbnailUrl`, `durationSec`, `uploadProgress`, `status` and `errorMessage`.

## Events

| Event | Payload Type | Description |
|-------|-------------|-------------|
| `cancelClick` | `AttachmentFile` | Emitted when the ✕ button is clicked while the tile is in flight (`uploading` or `pending`) |
| `removeClick` | `AttachmentFile` | Emitted when the ✕ button is clicked in any other status |
| `retryClick` | `AttachmentFile` | Emitted when the retry badge on a `failed` tile is clicked |
| `tileClick` | `AttachmentFile` | Emitted when an `uploaded` image or video tile is clicked or activated with Enter/Space. Not emitted for file or audio tiles |

## Upload States

The tile maps `tile.status` (`AttachmentTileStatus`) to a centre affordance:

| Status | Affordance | What the tile shows |
|--------|-----------|---------------------|
| `uploading`, `pending` | Progress | Dark scrim with a progress ring. The ring spins indeterminately until `uploadProgress` is greater than `0`, then fills by percentage. The ✕ button cancels |
| `uploaded` | None | No overlay. Image/video tiles become clickable; audio tiles become playable. The ✕ button removes |
| `failed` | Retry | Red border, a centred retry badge, and the inline text "Tap to retry" in place of the meta line |
| `rejected`, `error` | Error | Red border, a centred error badge, and the inline text "Upload failed". Hovering or focusing shows a tooltip with `errorMessage`, falling back to "Upload failed" |
| `cancelled` | None | No overlay |

A `rejected` tile is terminal: it has no retry control and can only be removed.

## Accessibility

- Clickable image/video tiles get `role="button"`, `tabindex="0"` and an `aria-label` of the file name
- The ✕ button is labelled "cancel" while uploading and "remove" otherwise (localized)
- The retry badge is a labelled button; the error badge has `role="img"` with a localized "Upload failed" label
- The error tooltip uses `role="tooltip"` and also opens on keyboard focus
- Focus rings use `--cometchat-focus-ring-width` and `--cometchat-focus-ring-color`
