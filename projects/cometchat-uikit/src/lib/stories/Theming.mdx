# Theming

CometChat Angular UIKit uses a CSS variable system for theming. All components read from a shared set of design tokens — change the tokens and every component updates automatically.

## How Themes Work

Themes are applied via the `data-theme` attribute on a container element. The UIKit ships with `light` (default) and `dark` presets defined in `css-variables.css`.

```html
<!-- Light theme (default) -->
<div data-theme="light">
  <cometchat-conversations></cometchat-conversations>
</div>

<!-- Dark theme -->
<div data-theme="dark">
  <cometchat-conversations></cometchat-conversations>
</div>
```

You can apply `data-theme` at any level — `document.documentElement`, `document.body`, or a specific container. The Storybook toolbar applies it to `document.documentElement` so all stories update simultaneously.

## Switching Themes at Runtime

```typescript
// theme.service.ts
@Injectable({ providedIn: 'root' })
export class ThemeService {
  setTheme(theme: 'light' | 'dark'): void {
    document.documentElement.setAttribute('data-theme', theme);
    localStorage.setItem('cometchat-theme', theme);
  }

  getTheme(): 'light' | 'dark' {
    return (localStorage.getItem('cometchat-theme') as 'light' | 'dark') || 'light';
  }

  initTheme(): void {
    const saved = this.getTheme();
    const system = window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
    this.setTheme(saved || system);
  }
}
```

```typescript
// app.component.ts
export class AppComponent implements OnInit {
  constructor(private themeService: ThemeService) {}

  ngOnInit(): void {
    this.themeService.initTheme();
  }
}
```

## Creating a Custom Theme

Override variables in your global stylesheet — no need to touch component files.

```css
/* styles.css — applied globally */
[data-theme="brand"] {
  --cometchat-primary-color: #E91E63;
  --cometchat-primary-color-hover: #C2185B;
  --cometchat-font-family: 'Poppins', sans-serif;
  --cometchat-radius-2: 12px;
  --cometchat-radius-3: 20px;
}
```

```typescript
// Activate your custom theme
document.documentElement.setAttribute('data-theme', 'brand');
```

## Storybook Theme Toolbar

The Storybook toolbar includes a theme switcher (circle icon). Selecting **light** or **dark** sets `data-theme` on `document.documentElement`, `document.body`, `#storybook-root`, `.sb-show-main`, `.sbdocs-wrapper`, and all `.docs-story` elements — so both the canvas and the Docs tab update together.

## Best Practices

- Always use `var(--cometchat-*)` tokens — never hardcode hex values or pixel sizes
- Apply `data-theme` at the highest possible ancestor so all components inherit it
- Test both light and dark themes before shipping any customization
- Use the Accessibility panel in Storybook to verify contrast ratios after overriding colors
