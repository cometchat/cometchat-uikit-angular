## What is CometChat Angular UIKit?

CometChat Angular UIKit is a comprehensive component library built on Angular 17+ that provides everything you need to add real-time chat to your application. It follows Angular-native patterns — services with DI, signals for reactive state, `ng-template` projections for customization — with no DataSource or Decorator patterns from React.

Key highlights:

- **50+ pre-built components** from simple avatars to full conversation panels
- **CSS variable theming** — switch between light and dark with a single `data-theme` attribute
- **19 built-in locales** with runtime language switching
- **Full keyboard accessibility** — Tab, Enter, Space, Escape, Arrow keys throughout
- **ARIA support** — screen-reader-friendly markup on every component
- **Angular signals** — reactive state without RxJS boilerplate where appropriate

## Quick Start

```bash
npm install @cometchat/chat-uikit-angular
```

```typescript
// main.ts — initialize before bootstrapping
import { CometChatUIKit } from '@cometchat/chat-uikit-angular';

await CometChatUIKit.init({ appId: 'YOUR_APP_ID', region: 'us', authKey: 'YOUR_AUTH_KEY' });
await CometChatUIKit.login({ uid: 'USER_UID' });

bootstrapApplication(AppComponent, appConfig);
```

```html
<!-- app.component.html -->
<cometchat-conversations (itemClick)="onConversationClick($event)"></cometchat-conversations>
```
